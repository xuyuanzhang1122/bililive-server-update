快速开始

三步跑起来

Linux / macOS / WSL，复制命令按提示回车即可。

1

跑安装命令

终端粘贴 curl -fsSL https://image.xumy.art/install.sh | bash，按提示选目录和端口。

2

打开控制台

浏览器访问 http://你的IP:8080，添加直播间、开启 API Key。

3

装上 iOS App

下载 IPA 签名安装，填服务器地址和 Key，开始随身刷录播。
